## 1. 실험 설계

| 항목 | 내용 |
|---|---|
| 목적 | ① 전처리(앞뒤 무음 제거·음량 정규화) 효과 ② STT 모델 크기별 전사 일치도·속도 비교 |
| 평가 데이터 | 녹음 [ ]건 (화자 [ ]명, 문장 [ ]개, 조용한 환경 [ ]건 / 소음 환경 [ ]건) |
| 분리 | 개발용 녹음과 별도 세션에서 새로 녹음, 파라미터 조정에 미사용 |
| 고정 조건 | 언어 ko, beam_size 5, VAD 사용, CPU int8, 동일 정규화 규칙 |
| 비교 조건 | base/raw, base/enhanced, small/raw, small/enhanced |
| 지표 | WER(어절), CER(공백 제외 문자), STT 처리 시간(ms) |
